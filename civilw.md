# civilw.bas

This program required **both** corrections from the OCR/transcriptions, and adjustments to the code as part of porting it.

## OCR/Transcription Corrections

About half of the calculations were transcribed with errors; some had additional/missing parenthesis, occasional variable name errors, and a number of cases of `*` and `+` being transposed.

## Porting

Porting was effectively limited to reducing a few lines that ran longer than MS-BASIC's 72-character line-length limit.
